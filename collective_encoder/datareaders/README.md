# Data Readers

This module contains classes that read raw data files from disk (e.g., molecular trajectories like `.xtc`, or tabular outputs like PLUMED files) into memory in a format that the `datamodules` and `datalabelers` can process.

## Interface

All datareaders must inherit from the `BaseDatareader` class in `base.py`.

### `BaseDatareader`
A `CEModule` subclass that establishes the standard for loading raw data.
Subclasses should implement:
- `read_trajectory(self, indices: List[List[int]], labeler_type, labeler_args)`: This method is called by the datamodule and is responsible for actually parsing the raw data, applying the specified labeler, and returning the structured data and labels, typically as a tuple.

## Available Readers

- `TrajectoryReaderBase` & `CompressedTrajectoryReader`: Basic readers for compressed molecular coordinate trajectories like `.xtc`, `.dcd`, `.trr` (leveraging `MDAnalysis` under the hood).
- `PlumedOutputReader`: Reads plain text tabular data typically generated by the PLUMED enhanced sampling plugin (COLVAR).

### Processors
Processors can be passed via `args` to `TrajectoryReaderBase` implementations to modify the trajectory reading behavior.
- `Chunk`: Expands sequence start indices into frame ranges of a specified length.
- `CoarseGrain`: Coarse-grains raw frames by averaging positions and labels over a window.
- `Filter`: Filters frames based on label values.
