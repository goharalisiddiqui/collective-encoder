# Data Readers

This module contains classes that read raw data files from disk (e.g., molecular trajectories like `.xtc`, `.npz` datasets like MD17, or tabular outputs like PLUMED files) into memory in a format that `datamodules` and `datalabelers` can process.

## Interface

All datareaders must inherit from the `BaseDataReader` class in `base.py`.

### `BaseDataReader`

A `CEModule` subclass that establishes the standard interface for loading raw data:
- `read(self, labeler_type: str, labeler_args: dict, **kwargs)` (and `read_trajectory` on trajectory readers): Reads the requested frames/rows, computes target labels using the specified `labeler_type`, and returns the structured data and labels.
- `get_total_frames(self) -> int`: Returns the total number of frames or records available in the data source.
- `get_label_names(self) -> List[str]`: Returns the list of label column names generated by the labeler.
- `check_labeler_compatibility(self, labeler_id: str)`: Validates that `labeler_id` is listed in `_COMPATIBLE_LABELERS`.

## Registration & Resolution

Data readers are registered under the `"datareaders"` kind in [`__init__.py`](__init__.py) using `collective_encoder.common.registry`:
- **Kind definition**: `define_kind("datareaders", BaseDataReader)`
- **Resolution**: `get_module("datareaders", datareader_type)` from `collective_encoder.common.registry` (there is no `resolver.py` in `datareaders/`).
- **Adding a new DataReader**: Subclass `BaseDataReader` and register it in `_BUILTINS` inside `datareaders/__init__.py` or from an external package via:
  ```python
  from collective_encoder.common.registry import register
  register("datareaders", "MY_READER", "my_package.datareaders", "MyDataReader")
  ```

## Available Readers

| Registry Key | Class | Description |
| :--- | :--- | :--- |
| `COMPRESSED_TRAJECTORY` (or `XTC`) | `CompressedTrajectoryReader` | Reads compressed molecular coordinate trajectories (`.xtc`, `.dcd`, `.trr`) using `MDAnalysis` and returns `ase.Atoms` structures. |
| `PLUMED_OUTPUT` | `PlumedOutputReader` | Reads plain-text tabular collective variable files generated by PLUMED (`COLVAR`). |
| `MD17` | `MD17Reader` | Downloads, caches, and reads `.npz` molecular trajectories from the MD17 / rMD17 benchmark datasets. |

### Processors (`datareaders/processors/`)

Processors can be passed via `processors` in `datareader_args` to `TrajectoryReaderBase` subclasses to transform frame indices, structures, or labels during reading:
- `Chunk`: Expands sequence start indices into contiguous frame ranges of length `sequence_length`.
- `CoarseGrain`: Coarse-grains raw frames by averaging atomic positions and labels over `cg_window`.
- `Filter`: Filters out frames whose label values fall outside `[min_val, max_val]`.

## Example Configuration

```yaml
datamodule_type: COORDINATES
datamodule_args:
  train_size: 1000
  batch_size: 256

  datareader_type: COMPRESSED_TRAJECTORY
  datareader_args:
    topology_file: "system.pdb"
    trajectory_file: "trajectory.xtc"
    selection: "backbone"
    parallel: true

    processors:
      - type: CoarseGrain
        args:
          cg_window: 10
          sequence_length: 5
      - type: Filter
        args:
          label_index: 0
          max_val: 2.5
```
